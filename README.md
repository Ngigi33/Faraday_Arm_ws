# Faraday_Arm_ws

## Overview
Faraday Arm workspace containing ROS 2 packages for the Faraday robotic arm manipulator. This workspace originated from URDF models generated by Fusion 360 and has been converted from ROS 1 to ROS 2 for compatibility with modern ROS distributions.

## Packages

### xarm7_faraday_description
**Status**: ✅ ROS 2 Compatible (Updated)

Robot description package for the 7-DOF xarm7 manipulator. Contains URDF model, meshes, and launch files.

**Origin**: Generated from Fusion 360 using fusion2urdf tool (initially ROS 1 package)

### faraday_description
**Status**: ✅ ROS 2 Compatible

Additional Faraday manipulator description files.

### faraday_cpp_examples
**Status**: C++ example nodes

### faraday_py_examples
**Status**: Python example nodes

## ROS 1 → ROS 2 Conversion Documentation

### What Was Generated from Fusion 360

The Fusion 360 URDF generator (`fusion2urdf`) created a ROS 1 package structure:
- **package.xml**: Format 2 with catkin build system
- **CMakeLists.txt**: CMake 2.8.3 with catkin macros
- **URDF files**: xarm7_faraday.xacro and supporting mesh files
- **Launch files**: ROS 1 XML format with legacy syntax

### Changes Made for ROS 2 Compatibility

#### 1. **package.xml Migration**
| Aspect | ROS 1 | ROS 2 |
|--------|-------|-------|
| Format | `format="2"` | `format="3"` with schema declaration |
| Build Tool | `<buildtool_depend>catkin</buildtool_depend>` | `<buildtool_depend>ament_cmake</buildtool_depend>` |
| Dependencies | `<build_depend>`, `<exec_depend>` rospy | Removed (not needed for pure description) |
| Export | None | `<build_type>ament_cmake</build_type>` |
| Test Framework | Implicit | `ament_lint_auto`, `ament_lint_common` |

**Updated file structure** (`xarm7_faraday_description/package.xml`):
```xml
<?xml version="1.0"?>
<?xml-model href="http://download.ros.org/schema/package_format3.xsd" schematypens="http://www.w3.org/2001/XMLSchema"?>
<package format="3">
  <name>xarm7_faraday_description</name>
  <version>0.0.0</version>
  <description>URDF description of xarm7 Faraday robotic arm</description>
  <maintainer email="syuntoku14@todo.todo">syuntoku14</maintainer>
  <license>TODO</license>

  <buildtool_depend>ament_cmake</buildtool_depend>

  <test_depend>ament_lint_auto</test_depend>
  <test_depend>ament_lint_common</test_depend>

  <export>
    <build_type>ament_cmake</build_type>
  </export>
</package>
```

#### 2. **CMakeLists.txt Migration**
| Aspect | ROS 1 | ROS 2 |
|--------|-------|-------|
| Min CMake | 2.8.3 | 3.8 |
| Package Manager | `find_package(catkin ...)` | `find_package(ament_cmake)` |
| Configuration | `catkin_package()` | `ament_package()` |
| Install Rules | catkin variables | Standard CMake paths |
| Testing | catkin test macros | `ament_lint_auto` |

**Key changes**:
- Removed all `catkin_package()` configuration macros
- Replaced `${catkin_INCLUDE_DIRS}` and `${CATKIN_PACKAGE_*}` variables with standard CMake
- Updated install rules to use `share/${PROJECT_NAME}`
- Simplified to focus on file installation (URDF, meshes)

**Current CMakeLists.txt structure**:
```cmake
cmake_minimum_required(VERSION 3.8)
project(xarm7_faraday_description)

if(CMAKE_COMPILER_IS_GNUCXX OR CMAKE_CXX_COMPILER_ID MATCHES "Clang")
  add_compile_options(-Wall -Wextra -Wpedantic)
endif()

find_package(ament_cmake REQUIRED)

install(
  DIRECTORY urdf meshes
  DESTINATION share/${PROJECT_NAME}
)

if(BUILD_TESTING)
  find_package(ament_lint_auto REQUIRED)
  set(ament_cmake_copyright_FOUND TRUE)
  set(ament_cmake_cpplint_FOUND TRUE)
  ament_lint_auto_find_test_dependencies()
endif()

ament_package()
```

#### 3. **Launch Files Migration**

Original ROS 1 XML launch files have been converted to ROS 2 Python launch files:

| File | Purpose | ROS 1 Syntax | ROS 2 Changes |
|------|---------|-------------|---------------|
| `display.launch.py` | RViz visualization | XML with `$(find ...)` | Python with `get_package_share_directory()` |
| `gazebo.launch.py` | Gazebo simulation | XML includes | Python IncludeLaunchDescription |
| `controller.launch.py` | Controller manager | XML node spawning | Python Node actions |

**Key Launch File Conversions**:

**display.launch.py** - RViz + Joint State Publisher:
```python
- Loads URDF via joint_state_publisher_gui
- Starts robot_state_publisher
- Launches rviz2 with configuration file
- No more $(find ...) substitutions
```

**urdf.rviz** - RViz configuration:
```text
- Updated panel/plugin class names from ROS 1 (`rviz/...`) to ROS 2 (`rviz_default_plugins/...`)
- Removed legacy `Panels:` UI section that caused rviz2 to fail loading `rviz_default_plugins/Displays`
- Keeps Grid, RobotModel, TF, and standard RViz tools compatible with rviz2
```

**gazebo.launch.py** - Gazebo Simulation:
```python
- Includes gazebo_ros launch via IncludeLaunchDescription
- Spawns xarm7_faraday robot using spawn_entity.py
- Remaps joint_states topic
- Uses PathJoinSubstitution for file paths
```

**controller.launch.py** - Controller Manager:
```python
- Loads controller.yaml configuration
- Spawns ROS 2 control_node
- Starts controller_spawner for position controllers
- Updated controller names: Revolute_1, Revolute_2, etc. (spaces → underscores)
```

### Build & Install Process

**ROS 2 Build**:
```bash
cd ~/Faraday_Arm_ws
colcon build --packages-select xarm7_faraday_description
```

**Install location**:
```
~/Faraday_Arm_ws/install/xarm7_faraday_description/share/xarm7_faraday_description/
├── urdf/
│   ├── xarm7_faraday.xacro
│   └── ...
├── meshes/
│   └── ...
└── launch/
    ├── display.launch.py
    ├── gazebo.launch.py
    └── controller.launch.py
```

### Using the Launch Files

After building and sourcing the workspace:

**1. Display robot in RViz**:
```bash
ros2 launch xarm7_faraday_description display.launch.py
```

**2. Spawn in Gazebo simulation**:
```bash
ros2 launch xarm7_faraday_description gazebo.launch.py
```

**3. Start controller manager**:
```bash
ros2 launch xarm7_faraday_description controller.launch.py
```
